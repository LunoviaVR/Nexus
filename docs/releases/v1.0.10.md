# Nexus 1.0.10

## ✨ New

- **What's new, inside Nexus.** The new megaphone next to the bell in the top bar opens the release notes for every version of Nexus, so you can see what changed without leaving the app. After Nexus updates, it shows you what's new once, the first time it opens. You can also find them in **Settings → Updates → Release notes**, or by typing *What's new* in **Ctrl + K**.
- **OLED theme.** **Settings → Appearance → Theme → OLED** turns the whole app true black, so OLED screens switch those pixels off. Your accent color carries over.
- **VRChat's status in the top bar.** Where it used to say **Live**, Nexus now shows VRChat's own service status from [status.vrchat.com](https://status.vrchat.com). It says **Stable** when everything works. When VRChat reports a problem, it changes color and says what's going on: **Degraded**, **Partial outage**, **Major outage** or **Maintenance**. Hover it to see the incident and which services are affected, and click it to open VRChat's status page. Nexus checks once a minute while it's on screen. Whether Nexus's own live updates are connected, which **Live** used to show, is in the same hover.

## 🛠️ Fixed

- The "Connecting to VRChat…" message while Nexus starts no longer shows garbled characters.

## ⬆️ Updating

Nexus offers this update automatically. Click **Install & restart** when the notification appears, or go to **Settings → Updates → Check now**.
