# Nexus 1.1.3

## 🛠️ Improved

- **Quicker update checks.** Nexus now asks its own update server whether a new version is out, and only fetches the update when there is one. If that server can't be reached, it falls back to the previous update file and then to GitHub, so updates keep arriving either way. Every update is still signed and checked by Nexus before it installs.

## ⬆️ Updating

Nexus offers this update automatically. Click **Install & restart** when the notification appears, or go to **Settings → Updates → Check now**.
