# Nexus 1.0.6

## ✨ New

- **See who opened an instance.** Instances in a world's page now show their owner, or the group for group instances. Click the name to open their profile or the group. Public instances don't have an owner, so they show none.
- **More on where friends are.** The **Right now** card on a profile shows how many people are in that instance (for example **14/32**) and who opened it. On your own profile the count comes straight from your game log, so it's always current.
- **Instance owner on Discord.** With **Show what you're playing** on, your Discord status now says whose instance you're in, for example *Friends+ · Hosted by Kitsune · Europe*. Private instances you've chosen to hide still only say you're in a private instance.

## 🛠️ Fixed

- **Removing favorites.** If you had more than 100 favorite avatars, some of them showed **Favorite** instead of the list they're in, so you couldn't remove them. Nexus now loads all of your favorites. If it can't load them, it says so and offers **Try again** instead of offering to add the avatar again.
- **Favorite friends.** The same limit could leave stars off some favorite friends. All of them show up now.
- **Clearing an avatar search.** In **Avatars → Discover**, emptying the search box now clears the results instead of leaving the last search on screen.
- **Platform filters in Discover.** **PC**, **Quest** and **iOS** now start switched on. Turn one off to hide avatars you could only use on that platform. Its tags also come off the result cards, and the performance filter only looks at the platforms you have on.

## ⬆️ Updating

Nexus offers this update automatically. Click **Install & restart** when the notification appears, or go to **Settings → Updates → Check now**.
