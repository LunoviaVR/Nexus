# Nexus 1.0.3

Fixes the real cause of the "429 Too Many Requests" errors.

## 🐛 Fixed

- **Rate limiting caused by profile pictures and avatar thumbnails.** Most VRChat pictures are served from VRChat's API, so each one counts against the same limit as boops and invites. Nexus was downloading them several at a time with no pacing, and kept going even while VRChat was asking it to slow down. With a big friends list, opening the Friends page or the friends panel could use up the limit in seconds, and the next boop or invite failed. Nexus now:
  - paces picture downloads from VRChat's API like every other request, and puts them behind the things you click;
  - pauses picture downloads too while VRChat has asked to slow down;
  - remembers a picture that just failed and waits before asking for it again, instead of re-requesting it every time it's shown;
  - leaves pictures from VRChat's CDN, which aren't limited, as fast as before.
- **A picture that failed once could stay broken.** Failed picture requests are no longer cached, so they load normally once VRChat allows it.

Pictures are saved (encrypted) the first time they load, so after a short while almost none need downloading again.

## ⬆️ Updating

Nexus offers this update automatically. Click **Install & restart** when the notification appears, or go to **Settings → Updates → Check now**.
