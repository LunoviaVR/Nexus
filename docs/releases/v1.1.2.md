# Nexus 1.1.2

## 🛠️ Improved

- **Faster, more reliable updates.** Nexus now downloads updates from its own update server on Cloudflare. If that server can't be reached, it falls back to GitHub automatically, so you always get updates either way. Every update is still signed and checked by Nexus before it installs.

## ⬆️ Updating

Nexus offers this update automatically. Click **Install & restart** when the notification appears, or go to **Settings → Updates → Check now**.
