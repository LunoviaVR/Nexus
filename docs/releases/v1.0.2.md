# Nexus 1.0.2

Fixes "Request failed (429 Too Many Requests)" when sending boops, invites and requests.

## 🐛 Fixed

- **Boops, invites, invite requests and friend requests failing with "429 Too Many Requests".** When VRChat asked Nexus to slow down, Nexus retried too soon and kept its background updates running, which kept you rate limited. Now Nexus:
  - waits as long as VRChat asks, using its own retry time, before trying again;
  - pauses **all** of its requests during that wait, so background updates can't extend the limit;
  - puts the things you click (boops, invites, requests) ahead of background updates;
  - shows a "Sending…" message while it waits, which turns into the result;
  - if VRChat's limit is longer than a short wait, tells you in plain words how long to wait instead of showing a raw error.
- **Double-clicking sent things twice.** Clicking Invite, Request invite, Add friend or a boop again while it's still sending no longer sends a second one.

## ⬆️ Updating

Nexus offers this update automatically. Click **Install & restart** when the notification appears, or go to **Settings → Updates → Check now**.
